Comment peut-on t’aider ?

↕️Ajouter une dépense ou un revenu

Utilise le bouton Ajouter en haut ou le + sur mobile. Choisis “J’ai payé” ou “J’ai reçu”, puis indique le montant, le libellé, la catégorie et le compte.

🌤️Comprendre le reste à vivre

Le reste à vivre combine les entrées et sorties du mois avec les mouvements récurrents encore prévus. Ton solde de compte reste séparé pour éviter toute confusion.

🔁Gérer les récurrents et prévisions

Dans À venir, enregistre salaires, abonnements ou factures. Quand un mouvement passe réellement, clique sur “C’est passé” pour le transformer en opération.

🎯Suivre un projet d’épargne

Crée un projet avec un montant cible, puis ajoute progressivement les sommes mises de côté. Flow affiche ta progression sans modifier automatiquement le solde du compte.

💳Utiliser plusieurs comptes

Ajoute tes comptes depuis Réglages → Mes comptes. Le sélecteur dans la barre du haut change le compte affiché partout dans l’application.

📦Sauvegarder, transférer et migrer

Tu peux utiliser un fichier JSON ou générer un code autonome à copier-coller sur un autre appareil. L’import remplace les données actuelles après confirmation. Flow récupère aussi automatiquement les anciennes données V2, V3 et V4 lorsqu’elles existent sur le même site.

🌓Changer le thème

Choisis Auto, Clair, Sombre, Neon Sakura ou Ocean Peace dans les réglages. Les couleurs, contrastes et icônes utilisent le thème actif automatiquement.

✏️Modifier ou supprimer un élément

Les icônes crayon et corbeille apparaissent à droite des opérations, récurrents et projets. Une confirmation protège les suppressions importantes.
